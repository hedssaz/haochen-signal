# 浩宸信号

“浩宸信号”（Haochen Signal）是一个以“苏浩宸、狼王与信号场”世界观为交互语言的 AI 编程 CLI。

它计划提供持续式终端对话、项目文件编辑、Shell 与 Git 操作、技术资料检索，以及针对受限操作的独立 AI 自动审查。世界观负责命名和氛围，真实路径、命令、差异、错误和风险信息始终以清晰的技术形式呈现。

## 当前状态

项目正处于模块化实现阶段；当前已具备配置、会话、安全工具、模型流式适配、信号上下文与主代理工具闭环等基础能力。

- 产品名：浩宸信号
- npm 包名：`haochen-signal`
- 全局命令：`haochen`
- 运行环境：Node.js 20+
- 开发语言：TypeScript
- 模型协议：OpenAI-compatible Chat Completions
- 已实现：真实工作区路径边界、结构化文件补丁、受控命令执行、确定性边界守卫、隔离红眼审查与统一工具执行门
- 边界策略：路径越界和非公开网络目标直接拒绝；curl 主机覆盖会先规范化非标准 IPv4 再判定地址范围；通用 Git、env、curl 与 Shell 命令必须确认，固定专用只读 Git 工具可直接执行
- 上下文：追加式 JSONL 会话支持可重复压缩的历史摘要投影、真实最近事件保留及固定 token 预算截断
- 主代理：严格核对纯文本 `stop` 与工具 `tool_calls` 完成协议；整批工具调用先校验非空唯一 ID 和合法 JSON，再按出现顺序执行，失败如实回传并按响应轮次允许一次修正；会话写入保持串行，中止记录位于所有已开始写入之后

## 设计目标

- 构建一个真正可用于项目开发的交互式 AI 编程代理。
- 让工作区内的常规操作顺畅执行，同时对受限操作进行独立的“红眼审查”。
- 支持任意兼容端点、自定义模型名、API 地址和请求头。
- 保留可替换的模型、工具、权限和会话模块边界。
- 同时生成正常发布版本与一个非压缩、包含运行依赖的超大单文件版本。

## 开发约定

- README、CHANGELOG 和项目说明使用中文。
- 正常源码保持模块化，超大单文件仅由构建流程生成。
- 敏感信息不得写入项目、会话或审计日志。
- 所有工具必须先通过结构校验、边界分类和必要的红眼审查或人工确认，再由统一执行门调用。
- 红眼审查模型由调用方显式指定；自动批准不得提高边界风险、扩大规范化范围或携带无法验证的执行约束。
- 工具执行前必须确认审计记录可追加；执行后的审计故障必须保留真实工具结果并附加警告，避免把已经发生的副作用误报为未执行。
- 主代理不会自动重试任何工具，尤其不会在修改性工具超时后重复执行；失败结果交由模型基于真实错误重新规划。
- 每次项目修改同步更新 CHANGELOG，并提交到 Git。

## 安装与首次配置

需要 Node.js 20 或更高版本。安装发布包后运行 `haochen` 即会进入交互终端；首次启动依次输入 OpenAI-compatible API 地址、模型和 API Key。

```bash
npm install -g haochen-signal
haochen
```

API 地址必须为不含用户凭据的 HTTP(S) 地址。API Key 的优先级为 `HAOCHEN_API_KEY` 环境变量、macOS 钥匙串、首次启动的临时输入。临时输入不回显，只保留在当前进程；配置文件仅保存 API 地址、模型和非敏感设置，权限为 `0600`，绝不写入 API Key。

## 交互终端

终端以 Ink 渲染信号场状态。`◆` 表示扫描、读取或修改，`◇` 表示验证，`◉` 表示红眼审查，`✓` 表示最终完成，`✗` 表示失败；工具失败会显示真实退出码和标准错误摘要，不会伪装为完成。模型在调用工具前的中间说明以普通条目显示，不会提前标记任务成功。

任务运行时，第一次 `Ctrl+C` 中止模型流或工具进程；任务仍在运行时再次按下会先持久化中断事件，再保存会话并退出。空闲时按一次 `Ctrl+C` 直接保存并退出。遇到操作确认时，界面会显示工具、风险与范围：按 `a` 仅允许本次、按 `s` 允许本会话、按 `d` 拒绝；非交互终端会明确拒绝确认请求。

| 命令 | 作用 |
|---|---|
| `/help` | 显示本地帮助 |
| `/status` | 显示模型、工作区、会话、上下文估算和阶段 |
| `/model [名称]` | 查看或仅切换当前会话模型 |
| `/diff` | 读取当前 Git 差异 |
| `/permissions` | 显示固定边界规则和本次会话许可 |
| `/compact` | 压缩可压缩的会话历史；失败时保留原历史 |
| `/clear` | 保存当前会话并创建新会话 |
| `/resume [ID]` | 恢复指定会话；不带 ID 时列出最近十个 |
| `/exit` | 保存会话并退出 |

所有斜杠命令仅由本地界面处理，不会发送给模型。`/diff` 只调用固定的只读 Git 工具；修改性或受限工具仍会经过边界守卫、红眼审查和必要的人工确认。
