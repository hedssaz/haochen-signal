# 浩宸信号

“浩宸信号”（Haochen Signal）是一个以“苏浩宸、狼王与信号场”世界观为交互语言的 AI 编程 CLI。

它计划提供持续式终端对话、项目文件编辑、Shell 与 Git 操作、技术资料检索，以及针对受限操作的独立 AI 自动审查。世界观负责命名和氛围，真实路径、命令、差异、错误和风险信息始终以清晰的技术形式呈现。

## 当前状态

项目已完成工程基础及首批核心安全模块，仍处于持续实现阶段。

- 产品名：浩宸信号
- npm 包名：`haochen-signal`
- 全局命令：`haochen`
- 运行环境：Node.js 20+
- 开发语言：TypeScript
- 模型协议：OpenAI-compatible Chat Completions
- 已实现：真实工作区路径边界、结构化文件补丁、受控命令执行与确定性边界守卫
- 边界策略：路径越界和非公开网络目标直接拒绝；通用 Git、env、curl 与 Shell 命令必须确认，固定专用只读 Git 工具可直接执行

完整设计见：

- [设计规格](docs/superpowers/specs/2026-07-25-haochen-signal-design.md)
- [实施计划](docs/superpowers/plans/2026-07-25-haochen-signal-implementation.md)

## 设计目标

- 构建一个真正可用于项目开发的交互式 AI 编程代理。
- 让工作区内的常规操作顺畅执行，同时对受限操作进行独立的“红眼审查”。
- 支持任意兼容端点、自定义模型名、API 地址和请求头。
- 保留可替换的模型、工具、权限和会话模块边界。
- 同时生成正常发布版本与一个非压缩、包含运行依赖的超大单文件版本。

## 开发约定

- README、CHANGELOG 和项目说明使用中文。
- 正常源码保持模块化，超大单文件仅由构建流程生成。
- 敏感信息不得写入项目、会话或审计日志。
- 每次项目修改同步更新 CHANGELOG，并提交到 Git。
