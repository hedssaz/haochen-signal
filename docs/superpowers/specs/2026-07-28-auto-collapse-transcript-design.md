# 自动收起执行过程设计

## 目标

- 每次工具调用在终端中只占一行，合并显示工具名、参数摘要与执行结果。
- 当前模型轮次出现首个非空回答增量时，立即收起本轮此前的思考、工具、审批、审查和工具结果。
- 不区分该回答是否为最终回答；只要开始输出回答，就执行收起。

## 范围

- 仅改变当前进程中的终端展示。
- 不删除会话内容、审计记录或模型上下文。
- 不影响先前任务的用户问题和最终回答。
- 工具运行期间仍显示当前工具行；失败结果也合并回对应工具行。

## 状态与渲染

`UiState` 记录当前任务在转录中的起点。收到首个非空 `assistant_delta` 时：

1. 清空当前任务的实时思考；
2. 从当前任务起点开始移除过程类条目；
3. 保留用户条目和已输出的回答条目；
4. 后续回答增量正常流式追加。

工具开始时追加一个单行工具条目；工具结束时更新最近的未完成工具条目，不再追加独立结果块。工具参数使用现有脱敏摘要，结果只保留简短状态或失败摘要。

## 异常处理

- 回答尚未开始时发生错误或中止，保留已有思考和工具信息，便于定位问题。
- 找不到对应工具开始条目时，工具结果退化为独立单行结果，避免信息丢失。
- 新任务重新设置任务起点，不影响前一任务的最终回答。

## 测试

- 首个非空回答增量会收起本轮过程。
- 空回答增量不会触发收起。
- 工具开始与成功、失败结果合并为一行。
- 回答前的错误或中止仍保留过程信息。
- 前一任务的内容不会被后一任务收起。
