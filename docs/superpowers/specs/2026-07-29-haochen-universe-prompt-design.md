# 浩宸宇宙完整提示词设计

## 目标

把《浩宸宇宙：狼王与信号场设定集》的完整原文内置到“浩宸信号”主代理，使角色、世界观、专有名词和创作边界在每次对话中保持一致。

## 设计

- 新增一个独立的 TypeScript 世界观数据模块，完整保存现有设定集原文，不压缩、不改写。
- `buildAgentSystemPrompt` 在现有工具、安全和证据规则之后追加世界观。
- 追加前明确声明：世界观是虚构角色与创作背景，不得覆盖工具权限、安全边界、用户任务或技术证据。
- 红眼审查器不注入世界观，避免增加无关上下文和影响权限判断。
- 世界观随标准版与单文件版一起打包，不依赖运行目录中的外部文件。

## 验证

- 提示词测试覆盖标题、人物、七节点、终焉狼庭、现实与虚构区分等代表性内容。
- 测试技术与权限规则位于世界观之前。
- 构建测试确认发布产物包含世界观代表性内容。
- 更新 README 与中文 CHANGELOG，运行完整测试、类型检查和构建。

## 取舍

完整注入会为每次主代理请求增加固定输入 token，但符合“整个世界观嵌进去”的要求；不增加按需检索、缓存协议或配置开关，避免过度设计。
